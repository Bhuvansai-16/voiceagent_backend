# Saying where an answer came from, out loud

Spoken citations are not written ones. Nobody wants a URL read to them.

Name the source in passing: "according to the Python release notes" or "Reuters
reported this morning". One clause, then the answer.

Say when the search did not settle it. "I found two different dates for that"
is a useful answer. Picking the more confident-sounding one and stating it
flatly is not.

Distinguish what you found from what you already knew. If the search returned
nothing useful and you are answering from memory, say so, because the caller
asked you to look it up and is entitled to know that you effectively did not.

Dates matter more than anything else when read aloud, since the caller cannot
see when the page was published. If a source is old, say how old.
